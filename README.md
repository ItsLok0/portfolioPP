## ♿ Point d'attention : navigation par onglets accessible

La section **Projets & Expériences** utilise un système de tabs entièrement navigable au clavier, conçu selon les recommandations RGAA :

- Attributs `role="tablist"`, `role="tab"`, `role="tabpanel"`
- Gestion du focus avec `tabindex`
- Navigation clavier via les touches `←` `→`
- États `aria-selected` mis à jour dynamiquement

> Un détail qui fait la différence — l'accessibilité n'est pas un afterthought ici, c'est intégré dès la conception.

## 💡 Pourquoi vanilla JS ?

Construire un portfolio sans framework était un choix délibéré : maîtriser les bases du DOM, du CSS natif et de l'accessibilité sans abstraction. Tout ce qui s'affiche ici est écrit à la main.
